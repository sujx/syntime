SynTime（与时偕行）进入 ALPHA。这个阶段我们只说已经成立的部分。

## 已经可以跑起来

- **金额口径守恒的整条链路**：全链路 Decimal，不做浮点；预聚合按天整日重算后覆盖写，重复跑不产生重复金额，负数退款行照常参与，可与账单总额对平。
- **六条业务唯一键的幂等**：账单、同步窗口、日聚合、资产、事件、厂商消息全部走唯一键兜底 + upsert，重复同步与并发触发不会脏数据。
- **云凭据信封加密**：AK/SK 以 AES-256-GCM 加密，HKDF-SHA256 按密钥版本派生数据密钥，AAD 绑定账号与字段防止密文挪用，主密钥不落代码，日志层自动脱敏。
- **财务角色的字段级隔离**：资源标识在序列化层统一置空，屏蔽只发生在一处。
- **查询侧三个接口**：项目汇总、资源明细下钻、成本趋势已上线并通过测试。
- **域名台账与到期预警**：资产模型含注册商 / 实名状态 / DNS / 到期时间 / 计费方式，CSV 批量导入可用，T-30 / T-7 / T-1 三档预警与预算超支预警由平台自算产出。

后端 313 个测试通过，前端 97 个测试通过；类型检查与 lint 全绿。

## 还在开发

- **云账单自动同步**（任务 1）尚未实现——所以页面上多数能力标着「部分上线」。当前可用演示数据或域名 CSV 导入先跑通链路。
- **厂商消息事件通道**按决议顺延二期；本期事件只有平台自算的三类。
- **闲置资源清单**只有索引与状态字段，判定服务与接口未开发。
- **异步报表导出**整卡待实现。
- **Docker 镜像未发布**，且届时仍需 PostgreSQL 与 Redis 两个依赖服务，单容器起不来 worker / beat。

## 现在怎么上手

源码部署：Python 3.12 + PostgreSQL 15+（我们在 17 上开发实测）+ Redis，四段命令。首页「快速开始」里每一步都可以直接复制，命令均已在开发机实跑。
